\# Parallel CSV Data Analytics Tool Using Multiprocessing



\## Project Overview



This project is a Python-based CSV data analytics tool that compares sequential and parallel processing using multiprocessing.



The system processes a large CSV dataset and performs calculations such as total quantity, revenue, discount, tax, profit, and product statistics.



\## Objectives



\- Process a large CSV dataset efficiently

\- Compare sequential and parallel processing

\- Measure execution time and speedup

\- Analyse multiprocessing performance

\- Visualize the performance results



\## Technologies Used



\- Python

\- Multiprocessing

\- Pandas

\- Matplotlib

\- CSV



\## Project Files



\- `main.py` - Main program

\- `data\_generator.py` - Generates the CSV dataset

\- `analytics.py` - Performs data analytics

\- `benchmark.py` - Measures sequential and parallel performance

\- `visualization.py` - Generates performance graphs

\- `sales\_data.csv` - Dataset

\- `results/` - Performance results and graphs



\## Dataset



The project uses a dataset containing 1,000,000 sales records.



\## Performance



The system compares sequential execution with parallel execution using multiple worker processes.



The results include:



\- Execution time

\- Speedup

\- Parallel efficiency
